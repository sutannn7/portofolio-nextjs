# Portofolio Web

Website portofolio pribadi dengan animasi halus dan tampilan responsif.

🔗 **Live:** [url-vercel-anda]

<img width="1920" height="1080" alt="Screenshot (620)" src="https://github.com/user-attachments/assets/e41baaf4-7e52-4362-9229-269a95d3fa92" />




## Fitur
- Halaman Projects dengan kartu interaktif dan modal detail
- Animasi transisi memakai Framer Motion
- Unduh CV dalam format PDF
- Responsif untuk desktop dan mobile

## Tech Stack
Next.js • React • TypeScript • Tailwind CSS • Framer Motion • Vercel

## Menjalankan Secara Lokal
```bash
git clone https://github.com/sutannn7/portofolio-nextjs.git
cd portofolio-nextjs
npm install
npm run dev
```
Buka `http://localhost:3000`.
